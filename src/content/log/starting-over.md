In 2021 I put up a single page with my name, a line saying I was a frontend engineer, and three icons. Then I didn't touch it for five years. It wasn't a bad page. It just had nothing to say.

This time the site has a job. It keeps a record of what I ship, with the help of agents: a project, an essay, a fix, a photo from a trip.[^1] Small counts. Unfinished doesn't.

## Why a day counter

Dates tell you when something happened. A day number tells you how long I've kept going. Day 001 is today. If you see Day 400 here next year, the habit stuck.

> Ship something small, regularly, with care.

I won't only write about code. Health, nutrition, history, investing, sports, cinema: anything under the sun is fair game.

The whole site is plain Markdown files in a Git repository. Adding an entry looks like this:

```md
---
title: Starting over
date: 2026-10-20
kind: note
summary: The start of a habit.
---

In 2021 I put up a single page…
```

The name at the top is mine, written in Kannada, the language I grew up speaking. Everything else is in English, for now.

See you soon.

[^1]: The old site is still in the repository as the first commit. I kept it on purpose.
